# easypaint — Whiteboard Tracer

Overlay a drawing on your phone's live camera and trace it onto a whiteboard or paper.

Live: https://likelystudying.github.io/easypaint/

## Layout

| Path | What it is |
|---|---|
| `index.html` | Page markup and styles |
| `js/app.js` | Core: camera, overlay rendering, gestures, panels, saving |
| `js/geometry.js`, `js/gestures.js`, `js/imaging.js`, `js/store.js` | Pure logic (unit-tested in Node) |
| `js/features/*.js` | One module per feature, enabled via `data-features` on `<html>` |
| `js/cvloader.js` | Loads `vendor/opencv.js` (OpenCV.js 4.12, about 11 MB) only when a feature needs it |

## Tests

```
npm install
npm test              # fixtures + unit + functional + integration (the full regression suite)
npm run test:unit     # Node, pure logic and OpenCV algorithms
npm run test:functional
npm run test:integration
```

- **Unit** (`tests/unit`): pure functions and OpenCV algorithms in Node, no browser.
- **Functional** (`tests/functional`): one feature at a time in Chrome with a fake camera.
- **Integration** (`tests/integration`): features together, on synthetic whiteboard videos with known geometry
  generated by `tests/fixtures/generate.mjs`.

Browser tests use the system Google Chrome (`channel: "chrome"`).
The full suite runs before every feature commit.
